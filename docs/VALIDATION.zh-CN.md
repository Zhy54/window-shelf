# 验证范围

## v0.1.2

x64 发行构建通过 62 项布局、层级和双屏检查。16 像素托盘图标和 32 像素程序图标均与设计稿逐像素一致。本机安装后实测一次展开和收起，1,255 次采样中，原生任务栏均未盖住 Shelf 的采样点。测量对象为窗口层级，逐帧显示效果仍取决于桌面环境。

## v0.1.1 回归验证

本机修复程序通过 51 项检查：原有 43 项交互/布局检查，加上 8 项原生窗口层级检查。使用不激活前台的小型临时窗口，复现“任务栏未获得焦点却抬到覆盖层上方”，验证恢复覆盖、保留更高浮层、焦点及尺寸不变、正确层级无需调整，以及再次抬高后的恢复。

本机窗口层级和合成桌面截图确认了原故障；部署后，用户确认悬停展开已能完整显示。桌面截图仅在本地诊断，未加入仓库或发行包。修复版尚未经历下一次完整注销/重启验收。下文的两屏移动验证来自 v0.1.0，本次补丁没有修改该功能。

这是经过本机测试的预览版，不表示兼容所有 Windows 应用。

- 内部回归覆盖行内别名、取消/重置、标题更新、应用/窗口排序、折叠、配置保存、悬停前后图标坐标与滚动位置稳定、固定行高及收起时关闭区域不可点击。
- 两屏临时窗口通过普通、最小化、最大化跨屏检查；最小化窗口在移动时保持最小化，定位到目标屏幕后才恢复。
- 在宽 92 像素的左侧竖向任务栏，以及上下排列的两块 2560×1440 显示器上检查过实际托盘边界与覆盖坐标。
- 实际 Windows 焦点测试可能受前台权限限制；内部分支测试不等于所有应用都能成功激活。
- 整体界面自动化未完成：外部自动化集成未获准访问新建应用。内部输入路径检查与本机实际使用是不同层次的证据。
- 混合 DPI、管理员窗口、特殊宿主程序、所有系统菜单、自动隐藏、全部全屏模式及超过两块屏幕仍未完整覆盖。
